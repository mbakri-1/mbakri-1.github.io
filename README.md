# Mohammed Fouad Portfolio

Fast portfolio website based on the required tutorial structure.

## Files
- `index.html`
- `css/style.css`
- `js/script.js`
- `images/`

## Quick run
Open `index.html` using VS Code Live Server.

## Publish on GitHub Pages
1. Create a public repository named:
   `mbakri-1.github.io`
2. In VS Code terminal, run:

```bash
git init
git add .
git commit -m "Initial commit: portfolio website"
git branch -M main
git remote add origin https://github.com/mbakri-1/mbakri-1.github.io.git
git push -u origin main
```

3. GitHub > repository Settings > Pages > Branch: main > Folder: /root > Save.
4. Live URL should be:
   `https://mbakri-1.github.io`

Replace `mbakri-1` if your GitHub username is different.
